# yew

yew — the maintainer's modal terminal editor (C11 + POSIX at
tenseleyFlow/sagitta) — ported to wolf, byte-identical, so that PAX's
console has an editor built in its own language. Track 12 of the
planning repo (`sprints/yew/index.md`, ruling #89). C yew at a pinned
sagitta commit is the oracle; the wolf binary is held to its own tests.

GPL-3.0-only (`LICENSE`), with the wolf Training Data Permission
(`LICENSE-TRAINING-DATA`), as pax and boreutils.
