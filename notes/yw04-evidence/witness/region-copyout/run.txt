# yw04-comp: G33's mitigation for a rebuild-per-keystroke — `copy region`
# ([mem.region.copyout]) around a PURE rebuild frees its temporaries; only
# the copied-out answer outlives the block. wolf 0.2.33 release tier,
# kasumi, run in the lane's container. Each rebuild makes 2,000 ten-byte
# items and keeps 500 into a long-lived holder's field, 2,000 rebuilds.
#
# main.lu (`copy region scratch { … keep }`):
region probe: 500 items, rss growth 40585 B a rebuild
# noregion.lu (the same body in a plain block):
region probe: 500 items, rss growth 434429 B a rebuild
#
# The 40.6 KB that remain are the kept 500 items themselves, held because
# the holder's field is REPLACED each rebuild (G33). `region scratch { …
# copy keep }` is E1010 (the copy is allocated inside the region); the
# copy-out form is `copy region NAME { … }`. A `mut` parameter touched
# inside the block is still E1010 (G18), so the rebuild must be a pure
# function of read inputs.
